# EVENTCLOCK — автоматические события

## Запуск

Эта версия использует локальный Node.js-сервер. Он получает данные с внешних источников и отдаёт их EVENTCLOCK через локальные `/api/...` маршруты, поэтому браузеру не нужно напрямую обращаться к сторонним API.

### Самый простой способ

Дважды кликни:

`start-eventclock.bat`

Скрипт запустит сервер и откроет:

`http://localhost:3000`

Окно Node.js оставляй открытым, пока пользуешься сайтом.

### Вручную

В папке проекта:

```bash
node server.js
```

Затем:

```text
http://localhost:3000
```

## Автоматические источники

- Genshin — календарь HoYoverse API;
- Honkai: Star Rail — календарь HoYoverse API;
- ZZZ — календарь HoYoverse API;
- Wuthering Waves — Game Calendar API;
- Arknights: Endfield — официальный раздел событий через локальный сервер;
- NTE — официальный сайт через локальный сервер;
- Infinity Nikki — официальный сайт через локальный сервер.

События обновляются при открытии сайта и затем примерно каждые 30 минут.

Если один источник временно недоступен, EVENTCLOCK не очищает все данные: для этой игры остаются резервные события.

В шапке сайта отображается количество успешно обновившихся источников из 7.


Обновление: официальные источники опрашиваются параллельно, максимум 8 страниц на игру, с таймаутом 8 секунд. Это предотвращает зависание проверки на минуту.
